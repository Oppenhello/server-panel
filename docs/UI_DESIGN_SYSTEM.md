## 1. 技术栈分析

| 项 | 实际 |
|---|---|
| 语言 | 原生 HTML5 + CSS3 + ES2018（无构建） |
| 框架 | 无（无 React/Vue），单文件 IIFE，DOM 直操 |
| 组件库 | 无，全部手写 |
| 样式体系 | 单个 `web/style.css`（1227 行），CSS 变量双主题 + 逐版追加补丁 |
| 页面入口 | `web/index.html` → `app.js`（282 行脚本引用） |

## 3. 主要问题清单（诊断）

### 3.1 结构与信息层级

1. **四张等宽卡 = 模板化仪表盘**。CPU 有"总数/刻度/每核/曲线/脚注"五层，磁盘只有一行百分比，却被强行拉成同宽同高 → 一边拥挤、一边空洞。
2. **进程/服务"等高"是假对齐**：进程只有 14 行（滚不动），服务 118 行（滚半天），两者内容量差 8 倍。
3. **主次不分**：CPU/内存是这台 2 核小机器最该先看的，网络/磁盘是次要，但视觉权重相同。
4. **列表与详情的密度倒挂**：服务器列表行高 ~60px（松），监控页表行 ~34px（紧），同一产品两种节奏。

### 3.2 样式系统（最严重）

5. **补丁层叠**：`style.css` 里有 v9 / v10 / v11 / v13 / v15 / v17 / v18 共 7 段"追加补丁"，同一选择器被覆盖 2~3 次（`.fs-row` 列宽定义 2 次、`.split > .panel` 高度 468→420 改两次），改一处要翻三个地方。
6. **数值不成体系**：间距用到 4/6/8/10/12/14/18/20/22/24/32 十种；圆角 6/9/12 三种无规则；字号 10.5/11/12/13/15/20 混用且无层级定义。
7. **玻璃拟态与阴影滥用点**：登录卡、弹层、顶栏各一套 `backdrop-filter` + 三套不同阴影参数。
8. **硬编码颜色残留**：补丁段里仍有 `rgba(255,255,255,...)` 直写，白天主题下对比度被吃掉。

### 3.3 交互与可访问性

9. 服务行的「重启/停止/日志」是三个裸文字按钮，**没有 `aria-label`、没有 focus 样式**，键盘不可达。
10. 进程表「结束进程」只有图标，靠 `data-tip` 提示；触屏无 hover 时提示不可见。
11. `.svc` / `.fs-row` 是 `div` + JS 委托，语义上应是可聚焦行；`tabindex` 缺失。
12. `#toast` 与 `#lg-err` 没有 `aria-live`，读屏用户收不到"保存成功/登录失败"。
13. 表单输入缺少 `name`，浏览器密码管理器无法归组。
14. 断线条 `position:fixed` 覆盖在顶栏之上，出现时会盖住主机名（实测截图里被盖住过）。

### 3.4 响应式

15. 只有 1080/860/760/640 四个断点，且都是"往下堆"；1080 以下四卡变 2×2，但曲线 canvas 高度固定 44px，窄屏下比例失真。

## 4. 改造范围与兼容风险

| 改动 | 范围 | 风险 | 处理 |
|---|---|---|---|
| 重写 `style.css` | 全文件 | 中：选择器遗漏导致样式丢失 | 逐类清单核对（见 §7），`check-refs` + `check-ui` 双验 |
| 布局重排（KPI 带 → 仪表墙） | CSS grid + 少量 DOM | 低：id 全保留，JS 不动 | 只改容器 class，不改 id |
| 列宽/行高调整 | 服务、文件、进程表 | 低 | 用统一 token |
| 语义与 a11y 补强 | 少量 DOM 属性 | 极低 | 只加属性，不改结构 |
| 双主题 | 保留 | 低 | token 全量覆盖，清理硬编码 |

**不动**：所有接口、所有 id、所有 JS 业务函数、后端、部署方式。

## 5. 设计方向（为什么是这个样子）

产品定位：**单/少数几台服务器的日常运维台**，使用者是能看懂 `load`、`systemctl` 的人。
参照物不是 SaaS dashboard，而是 **htop + Grafana 单机面板 + 机柜铭牌**：

- 屏幕的主角是**数字与行情**，不是卡片容器；
- 一屏之内要能回答三个问题：这台机器现在稳不稳、哪个进程在吃 CPU、哪个服务挂了；
- 界面要"安静"——没有装饰、没有渐变背景、没有大圆角，只有细线与刻度。

因此形状语言定为：**仪表墙（instrument panel）**——一整块带内部分隔线的区域，四组指标像仪表一样并排，而不是四张各自飘着的卡。

## 6. 设计 token

### 6.1 颜色

| 角色 | 夜晚（默认） | 白天 | 用途 |
|---|---|---|---|
| `--bg` | `#0b0c0e` | `#f4f3ef` | 页面底 |
| `--surface` | `#101216` | `#ffffff` | 面板 / 表格底 |
| `--surface-2` | `#15181d` | `#faf9f5` | 表头、工具条 |
| `--line` | `rgba(255,255,255,.07)` | `rgba(24,26,31,.10)` | 常规边线 |
| `--line-strong` | `rgba(255,255,255,.13)` | `rgba(24,26,31,.20)` | 输入框、按钮边 |
| `--text` | `#e9ebf0` | `#1a1d22` | 正文 |
| `--text-dim` | `#98a0ac` | `#4b535e` | 次要文字 |
| `--text-mute` | `#626a76` | `#858c97` | 标签、单位 |
| `--accent` | `#d8a35f` | `#9c6420` | 唯一强调色（主按钮、选中、当前值） |
| `--ok` | `#59b985` | `#2c8455` | 运行中 |
| `--warn` | `#d9a24a` | `#96601c` | 60~85% |
| `--bad` | `#d2645c` | `#b23f37` | >85% / 失败 / 危险操作 |

规则：强调色只出现在**可操作**或**当前状态**上，一屏不超过 3 处；百分比阈值色只染数字与进度条，不染卡片底。

### 6.2 字体

| token | 值 | 用途 |
|---|---|---|
| `--fs-xs` | 11px / 1.45 | 表头、单位、脚注 |
| `--fs-sm` | 12px / 1.5 | 表格正文、按钮、服务名 |
| `--fs-md` | 13px / 1.55 | 正文、输入框 |
| `--fs-lg` | 15px / 1.4 | 面板标题 |
| `--fs-xl` | 20px / 1.2 | 仪表主数字（仅 CPU/内存/网络/磁盘 4 个） |
| `--mono` | ui-monospace, SFMono, Menlo, Consolas | 所有数字、路径、单元名、日志 |

数字一律 `font-variant-numeric: tabular-nums`，刷新不跳动。

### 6.3 间距 / 圆角 / 描边

间距：`--s1 4 · --s2 8 · --s3 12 · --s4 16 · --s5 24 · --s6 32`（全部间距只能取这六档）
圆角：`--r1 4`（按钮/输入）、`--r2 8`（面板/弹层）、`--r3 999`（状态点/胶囊）
描边：常规 1px `--line`；强调 1px `--line-strong`；**不使用大于 1px 的装饰边框**。
阴影：仅弹层与下拉使用 `--shadow`；卡片**不加阴影**，靠边线分层。

## 7. 组件规范

### 7.1 按钮

| 类型 | 规格 |
|---|---|
| `.btn`（次） | 高 28，padding 0 10，1px `--line-strong`，字 12，圆角 `--r1`，hover 边框变 `--accent` + 文字 `--text` |
| `.btn.primary` | 底 `--accent`，字 `--accent-ink`，无边框，hover 提亮 6% |
| `.btn.danger` | 边框 `--bad` 40%，字 `--bad`，hover 底 12% |
| `.ico-btn` | 24×24，无边框，hover 底 `--hover` + 字 `--text`；`.danger` hover 字 `--bad` |
| `.tsw-btn`（主题） | 30×30 圆形，1px 边线，图标随 `data-theme` 旋转 180° |

所有按钮 `:focus-visible` = 2px `--accent` 外环 + 2px 偏移；`:active` 位移 0。
禁用态：`opacity .45` + `cursor: not-allowed`。

### 7.2 表单

`.field` / `.hfield`：标签 11px `--text-mute` 上置，控件高 34（`input`/`select`）或 36（登录 40），
底 `--bg`，1px `--line-strong`，圆角 `--r1`，focus 时边框 `--accent` + `0 0 0 3px` 的 12% 光晕。
错误行 `.lg-err`：11px `--bad`，`aria-live="polite"`，高度固定 16px 避免布局跳动。

### 7.3 仪表墙 `.kpis`

桌面：`grid-template-columns: repeat(12,1fr)`，CPU 4 / 内存 4 / 网络 4 / 磁盘 12（占满一行，横向 4 个挂载点）。
1180px 以下：CPU 6 / 内存 6 / 网络 6 / 磁盘 6。
760px 以下：单列，磁盘在最后。
外墙 1px `--line` + 圆角 `--r2`；**内部用 1px 分隔线**（`box-shadow: 1px 0 0 var(--line)`），不做卡片间距。

每个 `.card`：`padding 14 16`，结构为
`标题行（11px 标签 + 20px mono 主值）` → `4px 进度条` → `次要 KV（12px）` → `spark 曲线（高 40，贴底）` → `脚注（11px mute）`。

### 7.4 表格 / 列表

| 元素 | 行高 | 字号 | 说明 |
|---|---|---|---|
| 进程表 `tr` | 30 | 12 mono | 表头 11 大写字距 `.06em`，底色 `--surface-2` |
| 服务行 `.svc` | 32 | 12 | 状态点 6px 圆 + 单元名 mono + 动作 hover 显形 |
| 文件行 `.fs-row` | 30 | 12 | 列：名称 1fr / 大小 92 / 时间 118 / 权限 96 / 动作 84 |
| 服务器行 `.srv-row` | 52 | 13 | 列：名称 1.4fr / 地址 1.6fr / 内存 120 / 硬盘 120 / 操作 44 |

表格数字列右对齐，时间列 mono 居中；行 hover 只改底色（`--hover`），**不加位移**。

### 7.5 面板 `.panel`

头部 40px：15px 标题 + 右侧 11px 说明/计数，底边 1px 分隔。
进程面板与服一面板**各自独立高度**：进程 `max-height: 372px`，服务 `max-height: 372px`，
但两者都不再用 `height: 468px` 的"强行等高"，内容少时留白由 flex 吸收，内容多时内部滚动。

### 7.6 弹层

遮罩：`--scrim` + `backdrop-filter: blur(2px)`（只此一处）。
卡片：圆角 `--r2`，1px `--line`，`--shadow`；头 44px（标题 + 关闭），体 padding 16/20，脚 56px 右对齐按钮。
尺寸：确认/输入 420；添加服务器 560；大卡片编辑器 `min(1080px, 94vw) × min(86vh, 860px)`；日志全屏。

### 7.7 状态与反馈

- 运行中 `--ok`、失败 `--bad`、停止 `--text-mute`；状态点只染点，不染行。
- Toast：右下 20/20，底 `--surface`，1px 边，左侧 3px 状态条，`aria-live="polite"`，2.6s 自动消失。
- 断线条：**改为顶栏下方 24px 的插入条**（不再 fixed 覆盖），出现时把内容下推，避免遮住主机名。
- 空态：居中一行 12px mute 文案，例如「没有匹配的单元」。

## 9. 交互状态规范

| 状态 | 表现 |
|---|---|
| hover | 仅底色/边框/文字色变化，120ms |
| focus-visible | 2px accent 环，键盘可见、鼠标点击不出现 |
| active | 无位移（运维界面不做弹簧） |
| disabled | 45% 透明 + not-allowed |
| loading | 按钮文案替换（"登录中…"）+ disabled，不再插入 spinner |
| 断线 | 顶栏下插入条 + 数字停止刷新时页脚时间不变 |
| 空 | 一行说明 + 可行操作提示 |
| 危险 | 输入名称二次确认（沿用现有逻辑），按钮 `.danger` |

### 尚未解决的问题

1. **没有改造前后截图**：本机沙箱内 Chrome 无法启动（`platform_channel` 命名管道被拒），只能给线上地址 + 结构/度量核对。
